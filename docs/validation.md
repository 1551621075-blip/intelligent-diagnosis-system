# 本地验收记录

本记录只描述这个原创合成工程实际运行的结果，不是任何企业生产系统验收，也不是现场准确率承诺。

## 环境与复现

- Apple Silicon、macOS13、Python3.12。
- 项目依赖由`uv.lock`锁定；本次模型使用LightGBM4.7.0、NumPy2.5.4、scikit-learn1.9.1。
- 本地执行，不连接生产接口；没有GitHub Actions远端执行记录。
- 生成模型、完整请求、SQLite和完整演示报告保留在Git忽略目录，不随代码发布。

```bash
uv sync --locked --python 3.12
uv run pytest -q
uv run ruff check src tests scripts
node --check src/intelligent_diagnosis/static/app.js
uv run diag demo --directory runtime/acceptance-v2
```

演示目录不能重复覆盖，重跑须换新目录。测试使用临时目录，不会清空已有工作台数据。

## 1. 自动化回归

本次最终完整执行：**386 passed，1 warning，100.42秒**，包括新增CLI和真实退化模型门控用例。耗时仅是本机本次记录，不是性能SLA。

唯一警告来自Starlette TestClient对httpx适配的弃用提示；没有隐藏警告、跳过失败或把未知诊断当成功。以后更新依赖需重新验证适配。

测试按功能平铺在`tests/test_*.py`中：特征/模型/知识/挖掘/派单为模块测试，service/storage/API为集成，telemetry/lifecycle为贯穿场景；并未另外建立三个同名目录来重复测试。

重点包含：

- 真实LightGBM训练和推理，设备留出、冻结评测指纹、基线、反馈训练和模型文件完整性。
- 缺模型、缺值、异常窗口、未知主诉、领域冲突、极端范围输入不能自动确认。
- 知识图引用、环、类别映射、AND/OR三值根判定、固定正反例与安全下限。
- SQLite连接关闭、事务回滚、并发幂等、跨身份读取隔离、服务器端权限。
- 300/600/700/1000ms采样的持续告警；分批组合与重启；批内先告警后恢复；长批次多次触发；重叠冲突与密度上限。
- 派单资源原子预留、取消/完成、重复关闭与原始派单响应冻结。
- 时间戳超出0至2^63−1时HTTP422，数据库不写入，不发生SQLite溢出。
- API实际流式1MiB限长、非有限数、非法JSON、角色伪造、身份隔离、静态资源和导入无副作用。

### 实际发现并修复，而非仅正常样例

| 原问题 | 修复与回归 |
|---|---|
| OR解释叶子的反例被误当整体失败 | 服务只消费聚合根判定，保留解释叶子；固定知识回归 |
| 先精确裁2秒导致非整除采样无法持续触发 | 保留左边界前驱点，逐新增采样推进；600ms等回归 |
| 只检查批尾会漏掉已恢复的早段告警 | 批内时序扫描，多触发全部返回；全部短序列分批组合对照 |
| 关闭派单修改原动作幂等响应 | actions独立保存初次响应，关闭只推进当前工单状态 |
| 超大时间戳可进入SQLite后崩溃 | 输入模型统一int64非负边界，HTTP422与数据库无写入断言 |

## 2. 真实合成训练与留出结果

命令：`diag demo --directory runtime/acceptance-v2`，seed17，240台合成设备，每设备每类别2个事件，共3840事件。

| 分区 | 设备数 | 两域总事件数 |
|---|---:|---:|
| train | 144 | 2304 |
| validation | 48 | 768 |
| test | 48 | 768 |

同设备的全部事件在同一分区。每域测试384事件、每类96事件。有限超参和拒识阈值只在验证分区选择，随后测试冻结模型。

模型版本：`sim-lgbm-cde05b639e9c26baecd5`。版本与库版本、配置和制品内容相关，其他环境重建不承诺哈希完全相同。

| 冻结测试指标 | safety | low_voltage |
|---|---:|---:|
| 全部事件分类准确率 | 1.000000 | 0.997396 |
| 全部事件宏F1 | 1.000000 | 0.997396 |
| 模型可靠性门接受数 | 384/384 | 382/384 |
| 可靠性门覆盖率 | 1.000000 | 0.994792 |
| 接受子集分类准确率 | 1.000000 | 1.000000 |
| 先验基线准确率 | 0.250000 | 0.250000 |
| 线性逻辑回归基线准确率 | 1.000000 | 1.000000 |

**低压域LightGBM并未优于线性基线。** 合成类别容易分离，这些高分不能证明现实复杂度、因果正确性或LightGBM选型优势。低压测试实际有1个分类错误，可靠性门拒绝2个事件；不能只展示接受子集100%而隐去错误与拒识分母。

两个领域本次验证选出的最低分数0.95、最大归一化熵0.2、范围padding0.05，都是合成数据选择结果，不是现实设备标准，也不是严格校准概率。上表的接受率仅针对模型可靠性门，不包含知识证据/安全复核等完整服务终态。

实际构建wheel和sdist成功。`scripts/check_wheel.py`检查wheel包含模板/JS/CSS，在全新虚拟环境安装，然后在源码目录以外验证CLI、网页资源、401认证以及无模型诊断明确返回unknown。

## 5. 浏览器与版本发布链路

### 版本链路（已通过）

`tests/test_lifecycle.py`使用真实96设备训练制品、真实API和SQLite，未伪造模型指标或业务成功响应：

1. 诊断生成后由expert提交反馈，从API原样导出到`train_models`。
2. 新增1条真实训练事件和1台训练设备；验证/测试分区及评测指纹保持相同，低压模型文本内容真实改变。
3. 未注册模型激活被拒绝；注册后新版本指标不退化，激活成功，新诊断使用新版本。
4. 回滚到原历史批准版本成功，后续诊断恢复原版本；旧诊断、旧模型制品保持不变。
5. 激活/回滚重复操作不新增业务副作用；换seed的真实模型因评测集不一致被拒绝，也不能成为回滚目标。
6. 新增接口的权限、非法输入、无目标、重复动作、反馈冲突，以及取消/完成资源变化均经真实API校验。

7. 额外使用一次预先固定的256条**故意错误的合成人工标签**，通过真实诊断/反馈API导出后训练：低压宏F1由1.0下降到0.740656，安全仍1.0，评测指纹不变。注册后的真实退化候选被`409 regression_gate`阻断，活动版本、审批、动作和审计均不改变，也不能回滚到这个未批准版本。没有伪造报告或反复调参制造结论。

专项共25项通过。本次退化候选低于0.80，验证了最低门限拒绝分支；尚未用真实候选独立覆盖“仍高于0.80但低于当前版本”的相对退化分支。

### 浏览器（已通过，有明确范围）

`scripts/browser_smoke.mjs`在本机Chrome155.0.8059.85无头浏览器中实际加载网页、点击表单，连接回环地址上的真实API。使用全新临时浏览器配置与合成运行目录，不读取用户浏览器配置，不下载浏览器，不替换业务响应。

```bash
node scripts/browser_smoke.mjs
```

本次实际通过：

- 真实训练96台合成设备并注册模型，由admin在网页激活；operator加载样例并提交两条诊断，取得真实预测、证据与派单候选。
- 三种角色登录及控件可见性；expert确认派单后，取消返还工位与备件，完成仅返还工位。重复关闭不二次释放资源，新动作再次关闭显示真实`assignment_terminal` HTTP409。
- admin回滚表单发送正确的`version/action_id/reason`字段，未批准版本被真实`rollback_unapproved` HTTP409拒绝，活动模型不变。**浏览器本次没有验证成功回滚**；成功历史回滚由上面的API生命周期测试覆盖。
- 形似HTML的关闭备注在操作结果与审计中作为文本显示，不生成注入元素、不执行脚本。
- 登录后令牌输入清空，localStorage/sessionStorage、cookies、IndexedDB和Cache Storage为空；退出清空身份与结果，刷新不能自动恢复登录。未观察到令牌进入URL、JavaScript异常、失败请求或外部页面请求。
- 关闭本次API和Chrome后扫描临时文件，未发现原始令牌的UTF-8/UTF-16内容；临时浏览器配置、训练模型和运行目录已删除。

测试用的只读状态检查路由仅由烟测脚本在临时进程内加入，用于核对真实SQLite状态，不属于应用API。浏览器未覆盖遥测表单、知识发布、像素对比或全部安全情形；这不是穷尽性安全证明，也不是跨浏览器兼容认证。
